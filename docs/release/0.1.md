## In scope for 0.1

- Obsidian Community Plugin (desktop-only): Chat, Search, Status, Settings, onboarding
- Managed Prometheus Runtime sidecar (download + checksum + spawn) and optional custom binary path
- Local RAG: Markdown sync, chunking, FastEmbed embeddings, sqlite-vec + FTS5 index
- Dense search by default; optional hybrid / reranker via runtime env
- Grounded answers via local **Ollama** only (no cloud LLM / embedding APIs in base mode)
- Cited sources with note / heading navigation
- Scopes in UI: Auto / Vault / Current note / Current folder
- Streaming chat, cancel, ignored folders, diagnostics (redacted)
- Offline use after runtime + embedding + LLM models are installed

## Explicitly out of scope for 0.1

- Managed install of Ollama (user installs Ollama and pulls a model)
- UI for `selected_folders` scope (API/domain only)
- Persistent chat history (in-memory only)
- Alternative LLM runtimes (llama.cpp, etc.) and cloud/BYOK providers
- Mobile Obsidian
- Codesign / notarize of runtime binaries (tracked as post-0.1 hardening; SHA-256 verify remains required)
- github.io documentation site (helpful, not a code freeze item)
