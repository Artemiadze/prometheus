Prometheus

Ваши заметки. Ваши модели. Ваш компьютер.

AI-чат по vault в Obsidian — только локально.

Задавайте вопросы на естественном языке. Prometheus ищет заметки по смыслу, отвечает только по найденному и показывает источники — без облачных LLM и embedding API.

Community Plugin + локальный sidecar Runtime + Ollama. Desktop only.

Возможности

Один плагин — полный локальный RAG

UI в Obsidian, тяжёлая работа в managed Runtime, генерация через вашу модель Ollama. Всё остаётся на машине.

Grounded chat

Ответы только по найденным фрагментам vault. Если контекста мало — плагин так и говорит, а не выдумывает.

Семантический поиск

Ищите заметки по смыслу, не только по точным словам. Retrieval доступен и без полной генерации ответа.

Источники в ответе

К каждому ответу — ссылки на заметки и заголовки. Откройте источник в Obsidian и проверьте сами.

Автоиндексация

Markdown режется на chunks и эмбеддится локально. Правки обновляют индекс инкрементально.

Контекст заметок

Добавляйте конкретные заметки в запрос через / в поле ввода, когда нужен узкий контекст.

Области поиска

Scopes в UI: Auto, весь Vault, текущая заметка или текущая папка — сужайте retrieval под задачу.

Стриминг и отмена

Ответ появляется потоком. Можно отменить генерацию, перезапустить runtime и переиндексировать vault.

Managed Runtime

Плагин скачивает и запускает sidecar вне vault, проверяет checksum и версию — или укажите свой binary.

Любая модель Ollama

Выбирайте уже установленную локальную LLM. Prometheus не привязан к одной модели.

Интерфейс

Чат в Obsidian с цитированием источников

Спросите про Git, архитектуру или свои заметки — ответ опирается на vault, а не на общие знания модели.

Как работает

От вопроса до ответа с источниками

Три локальных процесса: тонкий плагин Obsidian, Prometheus Runtime и Ollama.

1

Семантический поиск

Runtime строит embedding запроса и достаёт релевантные chunks из sqlite-vec (опционально hybrid + rerank).

2

Grounded prompt

В контекст попадают только найденные фрагменты. Политика grounding запрещает дописывать факты «из головы» модели.

3

Локальная генерация

Ollama генерирует ответ на localhost. Плагин стримит текст и показывает источники для проверки.

Obsidian Community Plugin  (TypeScript UI)
            │  127.0.0.1
            ▼
Prometheus Runtime  chunking · FastEmbed · sqlite-vec · retrieval
            │  localhost
            ▼
         Ollama → локальная LLM
            │
            ▼
     Ответ + источники из заметок
