Частые вопросы

Короткие ответы на то, что чаще всего спрашивают про локальный режим и границы продукта.

Отправляет ли Prometheus мои заметки в облако?

Нет. В базовом продукте индексация, поиск и генерация идут локально через Prometheus Runtime и Ollama. Заметки не уходят в OpenAI, Anthropic, Google и подобные сервисы.

Работает ли офлайн?

Да, после установки binary Runtime и моделей для embeddings / LLM. Дальнейший чат и поиск интернет не требуют.

Есть ли поддержка мобильных устройств?

Нет. Prometheus только для desktop: sidecar Runtime и локальный процесс Ollama недоступны в мобильных приложениях Obsidian.

Что если ответа нет в моих заметках?

Prometheus не должен дописывать ответ из общих знаний модели и сообщит, что в vault недостаточно информации (insufficient_context).

Можно ли указать свой binary Runtime?

Да. В Settings → Runtime выберите Custom binary и укажите абсолютный путь к prometheus-runtime вместо managed-загрузки.

Нужно ли ставить Ollama отдельно?

Да. В 0.1 плагин не устанавливает Ollama за вас: скачайте Ollama, сделайте ollama pull … и выберите модель в Chat / Settings.

Где хранится индекс?

Векторный индекс и служебные данные Runtime живут вне vault (и вне .obsidian/plugins), чтобы не попадать в Obsidian Sync и Git. Исходный Markdown остаётся в vault.

Чем Chat отличается от Search?

Search возвращает релевантные фрагменты без вызова LLM. Chat делает retrieval и затем grounded-генерацию ответа с цитированием источников.
