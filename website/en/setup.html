Setup

Five steps to your first grounded answer over your notes. Prometheus is desktop-only: you need Obsidian on a computer, not the mobile apps.

1. Install Ollama and a model

Download and install Ollama. For ordinary laptops we recommend: 

ollama pull qwen3:4b-instruct-2507-q4_K_M

Any other installed model works too — pick it later in Chat / Settings.

2. Install the Prometheus plugin

  • Community Plugins — find Prometheus in the Obsidian catalog (once the release is published);
  • or install from a GitHub release / local build (main.js, manifest.json, styles.css).
Do not put the Runtime binary, models, or vector index inside the vault or .obsidian/plugins — they must stay out of Sync and Git.

3. Install Prometheus Runtime

On first setup, let the plugin download the managed binary outside the vault. The plugin verifies version and checksum.

Advanced / dev: in Settings → Runtime choose Custom binary and set an absolute path to your prometheus-runtime.

4. Open chat

  • ribbon icon;
  • or Command Palette → Open Prometheus Chat.

Re-run the onboarding wizard from the Command Palette if you need it again.

5. Wait for Ready and ask

The status bar should show Prometheus: Ready. The first vault index can take a while — that is expected.

Example questions:

  • “How do I create a branch, switch to it, and push?”
  • “Where did I describe the release process?”
  • “Summarize this architecture note” (with Current note scope).

After setup

  • You can go offline: chat and search stay local.
  • Note edits update the index incrementally.
  • If something breaks, open Status / Diagnostics and Restart runtime or Reindex vault.
