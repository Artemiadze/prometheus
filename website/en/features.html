Features

Product capabilities in release 0.1: what ships in the UI, how to use it, and what is deliberately deferred.

Chat

  • Multi-turn chat with a local LLM via Ollama.
  • Streaming answers and cancelable generation.
  • Cited sources: jump to the note / heading in Obsidian.
  • Pick any model already installed in Ollama.
  • Add specific notes via the / note picker.
  • Multiple chat tabs in the plugin panel.
Chat history in 0.1 lives in session memory and is not persisted across Obsidian restarts.

Search

  • Separate semantic search panel without requiring an LLM call.
  • Results are ranked fragments with scores and note navigation.
  • Same retrieval pipeline as Chat (dense; optional hybrid / rerank).

Search scopes

Available in the UI:

  • Auto — sensible scope from your current context;
  • Vault — the whole vault;
  • Current note — only the active note;
  • Current folder — the folder of the current note.

Scope selected_folders exists at the API/domain layer, but 0.1 has no multi-folder picker UI.

Status

  • Runtime and indexing status in a dedicated panel and the Obsidian status bar.
  • Prometheus: Ready means you can ask questions.
  • Commands to restart runtime and fully reindex the vault.

Settings

Runtime

  • Managed — plugin downloads a binary with checksum and owns the process.
  • Custom binary — your path to prometheus-runtime.
  • Install / Update / Restart runtime.

Indexing & embeddings

  • Indexing options and ignored folders.
  • Local embeddings via FastEmbed (no cloud embedding API).

LLM

  • Choose an Ollama model.
  • Base mode is local Ollama only — no BYOK / cloud providers.

Privacy & diagnostics

  • Diagnostics report with sensitive fields redacted.
  • Recent-events buffer for debugging.

Command Palette

  • Open Prometheus Chat
  • Open Prometheus Search
  • Open Prometheus Status
  • Open onboarding wizard
  • Open diagnostics
  • Reindex vault / Restart runtime (when available)

Onboarding

On first launch, a wizard helps install the managed Runtime, check Ollama, and wait for Ready. After that you can work offline.

In scope for 0.1

  • Desktop-only Community Plugin
  • Managed Runtime + custom path
  • Local RAG: Markdown sync, chunking, FastEmbed, sqlite-vec + FTS5
  • Grounded answers via Ollama
  • Cited sources, streaming, cancel, ignored folders, diagnostics

Out of scope for 0.1

  • Plugin-managed Ollama install
  • Multi-folder scope UI
  • Persistent chat history
  • Alternate LLM runtimes (llama.cpp, etc.) and cloud providers
  • Obsidian Mobile
