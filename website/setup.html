Установка

Пять шагов до первого grounded-ответа по вашим заметкам. Prometheus — desktop-only: нужен Obsidian на компьютере, не мобильное приложение.

1. Установите Ollama и модель

Скачайте и установите Ollama. Для обычных ноутбуков рекомендуем: 

ollama pull qwen3:4b-instruct-2507-q4_K_M

Можно использовать любую другую уже установленную модель — выберите её позже в Chat / Settings.

2. Установите плагин Prometheus

  • Community Plugins — найдите Prometheus в каталоге Obsidian (когда релиз опубликован);
  • или установите из GitHub release / локальной сборки (main.js, manifest.json, styles.css).
Не кладите Runtime binary, модели и vector index внутрь vault или .obsidian/plugins — они не должны попадать в Sync и Git.

3. Установите Prometheus Runtime

При первой настройке позвольте плагину скачать managed-бинарник вне vault. Плагин проверяет версию и checksum.

Advanced / dev: в Settings → Runtime выберите Custom binary и укажите абсолютный путь к своему prometheus-runtime.

4. Откройте чат

  • иконка на ribbon;
  • или Command Palette → Open Prometheus Chat.

При необходимости пройдите onboarding wizard ещё раз из Command Palette.

5. Дождитесь Ready и спросите

В status bar должно появиться Prometheus: Ready. Первая индексация vault может занять время — это нормально.

Примеры вопросов:

  • «Как создать ветку, переключиться на неё и отправить изменения?»
  • «Где у меня описан процесс релиза?»
  • «Кратко суммируй заметку про архитектуру» (с scope Current note).

После установки

  • Можно отключить интернет: чат и поиск идут локально.
  • Правки заметок подхватываются инкрементально.
  • При проблемах откройте Status / Diagnostics и при необходимости Restart runtime или Reindex vault.
