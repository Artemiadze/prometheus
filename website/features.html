Функционал

Ниже — продуктовые возможности релиза 0.1: что есть в UI, как этим пользоваться и что сознательно оставлено на потом.

Chat

  • Многоходовый чат с локальной LLM через Ollama.
  • Стриминг ответа и возможность отменить генерацию.
  • Цитирование источников: переход к заметке / heading в Obsidian.
  • Выбор модели из уже установленных в Ollama.
  • Добавление конкретных заметок в контекст через / note picker.
  • Несколько вкладок чата в панели плагина.
История чата в 0.1 хранится в памяти сессии и не персистится между перезапусками Obsidian.

Search

  • Отдельная панель семантического поиска без обязательного вызова LLM.
  • Результаты — релевантные фрагменты с оценкой и навигацией в заметку.
  • Тот же retrieval pipeline, что и у Chat (dense; опционально hybrid / rerank).

Области поиска (scopes)

В UI доступны:

  • Auto — разумный выбор области по контексту работы;
  • Vault — весь хранилище;
  • Current note — только активная заметка;
  • Current folder — папка текущей заметки.

Scope selected_folders есть на уровне API/domain, но отдельного UI выбора нескольких папок в 0.1 нет.

Status

  • Статус runtime и индексации в отдельной панели и в status bar Obsidian.
  • Состояние Prometheus: Ready означает, что можно задавать вопросы.
  • Команды перезапуска runtime и полной переиндексации vault.

Settings

Runtime

  • Режим Managed — плагин скачивает binary с checksum и управляет процессом.
  • Режим Custom binary — свой путь к prometheus-runtime.
  • Install / Update / Restart runtime.

Indexing & embeddings

  • Параметры индексации и игнорируемые папки.
  • Локальные embeddings через FastEmbed (без cloud embedding API).

LLM

  • Выбор модели Ollama.
  • В базовом режиме только локальный Ollama — без BYOK / cloud providers.

Privacy & diagnostics

  • Диагностический отчёт с маскированием чувствительных полей (redacted).
  • Буфер недавних событий для отладки.

Команды Command Palette

  • Open Prometheus Chat
  • Open Prometheus Search
  • Open Prometheus Status
  • Open onboarding wizard
  • Open diagnostics
  • Reindex vault / Restart runtime (когда доступны)

Onboarding

При первом запуске мастер помогает установить managed Runtime, проверить Ollama и дождаться Ready. После этого можно работать офлайн.

В scope 0.1

  • Desktop-only Community Plugin
  • Managed Runtime + custom path
  • Local RAG: Markdown sync, chunking, FastEmbed, sqlite-vec + FTS5
  • Grounded answers через Ollama
  • Cited sources, streaming, cancel, ignored folders, diagnostics

Вне scope 0.1

  • Установка Ollama самим плагином
  • UI для multi-folder scope
  • Персистентная история чата
  • Альтернативные LLM runtimes (llama.cpp и т.п.) и cloud providers
  • Obsidian Mobile
